# 바이브코딩 웹앱 개발 절차 PNG 디자인

## 목표

바이브코딩으로 웹앱을 개발하는 일반적인 절차를 초보자도 한눈에 이해할 수 있는 16:9 가로형 PNG 한 장으로 정리한다.

## 산출물

- 파일명: `바이브코딩-웹앱-개발절차.png`
- 위치: 프로젝트 루트
- 크기: 1920×1080px
- 배경: 순백색
- 언어: 한국어

## 정보 구조

전체 절차를 세 구간으로 묶는다.

1. 기획: 목표 정의, MVP 범위, 사용자 흐름, 기술 스택
2. 구현·반복: 기본 구조, 기능별 구현, 외부 기능 연결
3. 검증·출시: 통합 테스트, 보안·품질, 배포·피드백

구현 구간에는 `설명 → 코드 작성 → 실행 → 피드백 → 수정` 반복 고리를 시각적으로 강조한다. 하단에는 `작게 요청 → 직접 실행 → 결과 전달 → 수정` 핵심 원칙을 별도의 요약 띠로 배치한다.

## 시각 디자인

- 좌우로 진행되는 3단계 그룹형 레이아웃
- 단계별 번호와 짧은 제목을 우선하고 설명은 한 줄로 제한
- 차분한 파랑·청록·주황을 구간 구분에만 사용
- 연결선과 화살표로 진행 방향을 명확히 표시
- 여백을 충분히 두고 발표 화면에서도 읽히는 큰 한글 사용
- 생성형 이미지가 아닌 벡터 기반 도식을 렌더링하여 글자 정확도를 보장

## 완료 기준

- PNG가 1920×1080px이며 흰 배경이다.
- 10단계가 빠짐없이 올바른 순서로 표시된다.
- 반복 개발 고리와 하단 핵심 원칙이 명확히 보인다.
- 한글이 깨지거나 잘리지 않고 요소끼리 겹치지 않는다.
- 최종 파일을 직접 열어 시각적으로 검증한다.
