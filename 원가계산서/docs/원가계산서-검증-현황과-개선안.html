필수값 확인일부 동작공사명·발주기관·추정가격이 비면 생성 버튼을 끄고 누락 항목을 안내합니다.활성화된 모든 항목을 필수 처리하지 않으며, 유형·입찰방법에 따른 필수 규칙도 없습니다.

날짜·공휴일 확인동작 안함공고일·입찰마감일시·개찰일시를 직접 입력할 수 있습니다.초일 불산입 7일, 공휴일 여부, 다음 영업일까지 연장하는 규칙을 검사하지 않습니다.

1차 구현과 후속 개발

1차 · 공고문 초안부터 생성

  • 공사입찰공고 HWPX 템플릿 우선
  • 날짜와 금액은 사용자가 직접 입력·수정
  • 활성화된 모든 필수값 확인
  • 자리표시자 치환 후 HWPX 다운로드

후속 · 정확한 금액과 공고기간 확인

  • 용역·구매 유형별 템플릿 추가
  • 원가계산서 금액과 입력 금액 대조
  • 공고일 초일 불산입, 최소 7일 확보
  • 7일째가 공휴일이면 다음 영업일까지 연장
  • 공휴일 데이터 연동과 오류 안내

구현 마일스톤

  1. 화면 연결첫 화면 바로가기와 공고문 생성 경로를 연결합니다.
  2. 유형별 입력 폼전체 발주항목과 조건별 회색 비활성화를 구현합니다.
  3. HWPX 엔진XML 이스케이프, 자리표시자 치환, 재압축과 다운로드를 완성합니다.
  4. 템플릿·인수공사부터 용역·구매로 확장하고 한글에서 결과를 확인합니다.
